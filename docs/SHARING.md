# Sharing the project

For a quick review, send `docs/index.html`: it contains its own data and charts
and opens locally in a browser. Recipients do not need C++, Python or a web server.
The full ZIP additionally includes the implementation, data provenance, audit
exports and tests.

For a code repository, preserve the directory structure. The README is the entry
point; the report is under docs. Do not flatten all source and data files into one
folder. Build outputs and new run directories do not need to be committed.

A public static host can serve docs/index.html as a frozen research report. That
would not rerun the C++ engine or obtain new data. This project has not been
published or submitted anywhere for you.

Market-data rights are separate from the code's MIT license. Review your data
provider's terms before publicly redistributing raw files. The public-facing
report should retain its data source, date range, assumptions and limitations.

Describe the project as a historical research engine. Do not describe the losing
baseline as a profitable strategy, equate a training significance test with an investable opportunity.
